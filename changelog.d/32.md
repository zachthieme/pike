section: Bug fixes
- [user] A HEY sync now warns and counts a failure when a pending delete's retry fails, instead of discarding the error silently — so a briefly-unavailable `hey` during the reset procedure's "run a sync first" step can no longer look like a clean run (#32).
- [user] The sync report now names every orphaned Todo and every outstanding pending delete by id and title — listed under the counts in text output and carried as arrays in `--json` — independently of the orphan warn-once rule, so `pike --sync --dry-run --json` always lists what is still outstanding in HEY (#32).
