section: Bug fixes
- [user] HEY Sync and the dashboard's toggle now read and write notes files with Windows (CRLF) line endings correctly: a line is matched by its content regardless of its ending, each line keeps its own `\r\n` or `\n` when rewritten, and a line pike appends (a pushed `@hey` link's inbox import, `AppendTask`) uses `\r\n` when the file's existing lines do. Before, every Sync write to a CRLF line was refused as stale — so each run pushed a Todo, had the tag write refused, rolled the Todo back, and warned — and retitle, reschedule, and HEY-side completion were always refused too (#22).
