- [user] The dashboard no longer risks crashing when background scans overlap (the refresh tick, a post-toggle or post-editor refresh, and the `S` sync scan can all run at once): `Scanner.Refresh` now builds each result against a private snapshot of its cache and publishes it atomically, so concurrent scans no longer write the same maps at once — a data race Go could turn into a hard process abort (#23).
